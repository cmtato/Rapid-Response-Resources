Basic Local Alignment Search Tool (BLAST)

BLAST refers to a suite of local alignment tools hosted by NCBI that find regions of similarity between sequences. Through BLAST, you can align unknown “query” sequences against a selected database of known sequences (referred to as “subject” sequences) and assess the statistical significance of alignments or matches. BLAST can also be used to annotate genome coding regions and to find sequences similar to your query when trying to assess how detected microbes fit within the known diversity (e.g., phylogenetic analysis).

See CZ ID’s A Guide to BLAST for details.

Instructions for Running BLAST:

  1. Navigate to NCBI’s BLAST online tool found here and select the Nucleotide BLAST option.

  1. Copy the query sequences (make sure to retain the FASTA format) and paste in the box with the header "Enter accession number(s), gi(s), or FASTA sequence(s)".

  1. Scroll down and click the BLAST button on the bottom, left of the window. You will have to wait a few moments for the web server to run BLAST on your query sequences.

  1. Explore results once the BLAST Results page appears.





















BLAST Results

The results page includes a search summary and tabs to explore results using a description table, graphic summary, and/or alignments that can help determine the quality or accuracy of a given match. The results are displayed for one query sequence at a time. You can view the results for a different query sequence by selecting it from the Query dropdown menu.

Click here for a CZ ID’s detailed description of BLAST result tabs.

By default, the results page will display the Descriptions tab which includes a table listing all the sequences sharing similarity with the query and metrics to evaluate the matches. The table includes the following information:

  1. Description: Species name of the organism represented by the subject sequence (match in the database).

  2. Scientific Name: Scientific name of the organism represented by the subject sequence (match in the database). Clicking on the species name link will take you to the alignment.

  3. Max Score: Highest bit score calculated from matches and mismatches found in local alignments. The higher the max score, the better the alignment.

  4. Total Score: Sum of alignment scores for all of the sequence segments or local alignments. The higher the score, the better the alignment. When max and total scores are the same, there is one global alignment between the query and its match in the database. This means that the sequences can be aligned without long insertions or deletions.

  5. Query Cover: Percent of the query sequence length that is included in alignments against the subject sequence.

  6. E value: Indicates the number of hits or alignments that are expected to be seen by random chance with the same score or better. The lower the E-value, the more significant the alignment (the closer to 0, the better). E-value is the default metric used to sort the Descriptions table and normally gives the same sorting order as Max Score.

  7. Per. Ident: Percent of nucleotides or amino acids that are identical between the aligned query and the subject sequence. A query sequence can share low percent identity with a sequence and still be a significant match. It is essential to take the E-value into account and look for similarity between conserved regions (this will be more evident at the amino acid level)

  8. Accession: Unique accession ID assigned to the reference sequence in the NCBI database.



Identify the top scoring organism(s) for the first query sequence. Then, navigate to the results for the next query sequence using the Query dropdown menu.

NCBI ORF Finder

The NCBI Open Reading Frame (ORF) Finder searches for ORFs in sequences. An ORF is a stretch of DNA between start and stop codons. We identify ORFs to predict genes (or coding sequences) that are translated into protein. Based on known genomes, we can use ORF information to evaluate if we have the expected complete coding sequence of a given genome. Open reading frames shorter than expected, due to early stop codons, may point to sequencing errors.

Open reading frames detected in a Rhinovirus A genome sequence using NCBI ORF Finder. Rhinovirus genomes are known to encode a single polyprotein.

Instructions

To detect ORFs in the sequenced genome:

  1. Navigate to NCBI ORF Finder

  2. Paste the sequence in the provided box.

  1. Scroll down and and adjust the search parameters to focus on major non-overlapping ORFs (> 600 nt).

  1. Click the “Submit” button to start the search.
















ORF Finder Results

The results page includes a schematic of identified ORFs, ORF sequence information, and buttons to BLAST predicted protein sequences.

You can search protein sequence databases to find more information about detected ORFs. For the purposes of this exercise, change the BLAST Database to “Reference proteins (refseq_proteins)”. When you click the BLAST button, you will be directed to the BLASTp webpage given that you are now searching translated sequences against the protein database. Click the BLAST button to begin the search.

Look at the Description and Alignment tabs of the BLAST results page to see how well the predicted ORF aligns with known protein sequences.





NCBI Virus

NCBI Virus is a database for the retrieval, display, and analysis of a curated collection of virus sequences and large sequence datasets. Notably, the database contains standardized metadata so users can easily find sequences of interest.

NCBI virus home page





In NCBI Virus you can:

  • Find sequences similar to your query by running BLAST against the curated database

To find similar sequences to your query, paste the query in the provided box and click “Start search”.

  • Search for viral species or groups of interest using virus name or taxID

Type the virus name or taxID for the group of interest in the provided box.



  • Refine results by filtering based on metadata of interest.

Use the filter menu on the left hand side of the Search Results page to refine results. (e.g., how many Rhinovirus A genomes from South America are available?)
