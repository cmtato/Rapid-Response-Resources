CZ ID Training: ONT Reference Tables

QC Metrics Table - ONT

QC Metric

Definition

Passed Filters

The percentage of reads remaining after host filtering, quality filtering and subsampling, compared to the initial reads input. Tells you how many reads were used for final analysis.

Passed QC

Percentage of reads remaining after QC filtering to remove low quality bases (phred score < 9),

short reads (< 100 bp), and low complexity reads.

Total Reads*

The total number of reads uploaded.

Subsampled Fraction*

After QC filtering and host/human data removal, the remaining reads are subsampled to 1 million. This fraction specifies the ratio of subsampled reads to total reads passing QC and host/human filtering.

* Fields are not default in the samples table and need to be added by clicking on the column selector


The Sample Table only provides stats at the read level for you to keep track of how many reads made it through data pre-processing steps (e.g., QC filtering and subsampling) and, thus, were used for microbe detection. If you are interested in information at the base pair level, please see the Sample Overview report available through bulk download or look at the pipeline details on the Sample Report page

Sample Metrics Table

Report Metric

Definition

Bases per million (bPM)

Number of bases within all the reads aligning to a given taxon, including those assembled into contigs that mapped to the taxon, per million bases sequenced

Bases (b)

Number of bases within all the reads aligning to a given taxon, including those assembled into contigs that mapped to the taxon

Reads (r)

Number of reads aligning to a given taxon in the NCBI NT/NR database, including those assembled into contigs that mapped to the taxon

Contigs (contig)

Number of contigs aligning to the taxon in the NCBI NT/NR database

Contig bases (contig b)

Number of bases within all the reads that assembled into contigs aligning to a given taxon

Percent identity (%id)

Average percent identity between all the query sequences (contigs and unassembled reads) and their matching taxon

Length (L)

Average length of alignments between all the query sequences (contigs and unassembled reads) and their matching taxon. Note that values against NR are reported in base pairs

Expect value (E value)

Average expect value (E-value) of alignments against the NT and NR databases. The E-value represents the number of matches with similar quality one would “expect” to see by random chance. This parameter provides a measure of randomness. The lower the E-value, the lower the probability of getting a match or alignment by random chance (i.e., the closer the E-value is to 0, the better)

Samples with low % Passed QC likely contained many short sequences that were associated with adapter dimers or sequences that obtained low-quality scores during base-calling. >5%

A higher Passed Filters value is generally positive as it indicates that you have a greater amount of reads to analyze for non-host taxa.


What is the Sample Type for each of the samples?

  • Samples with a known microbiome (ie Stool, NP Swab, Environmental Samples, Sputum) tend to have a higher number of non-host reads due to greater microbial content in the samples.

  • Sterile site fluids (Serum, CSF, Plasma) tend to have fewer non-host reads and greater numbers of host reads.

  • Whole Blood tends to have a distribution of non-host reads in between these two extremes due to the high abundance of host cells.

<5%

Analysis Workflow - ONT RNA mNGS for respiratory viruses

Navigate

  1. Go to each sample report

  2. Filter category for viruses + non-phage


Complete a first pass sample report view

  1. Look at the list of detected taxa

  2. Record NT bPM, NT r, and any other relevant metrics

  3. Look at the coverage plot for each taxa and record your interpretation (low, medium, high coverage)

  4. BLASTn contigs from each candidate taxa and record what you find (specific, non-specific, etc)


Check negative water controls

  1. Navigate to the sample report for each negative water control included in the run

  2. For each taxa observed in the samples, record the NT bPM, NT r, and any other metrics in each water control

  3. If you have >1 water control, calculate the average signal for each taxa


Put it all together (background subtraction + interpretation)

  1. Subtract the background/water control signal from the sample signal for each taxa

  2. Interpret: real signal should be higher in samples than in water controls

Because mNGS sequencing is a research tool, we recommend completing some of the following steps to increase confidence in the hit.

  1. Reprep and sequence sample starting from a fresh extraction

  2. Resequence the completed library individually or in a pool without other samples with high abundance of the taxon (reduce barcode bleeding)

  3. Perform other confirmatory tests on the sample like qPCR

  4. Consider more advanced bioinformatics analysis to compare SNP pattern across samples
