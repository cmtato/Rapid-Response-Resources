Sheet 1: README

mNGS starter kit reagent list

Last updated 15 Sept 2026

This document is intended to provide guidance for reagent procurement to prepare for generating RNA metagenomics libraries for sequencing.

1. Start with the General reagents tab - these items are required for all workflows

Note the "Platform" field and procure items according to your intended sequencing platform (Illumina or ONT)

2. Select a Starter Kit Option - only one is needed and all are sufficient options for RNA mNGS library preparation
