# Slides and worksheets

Training slide decks with the activity and reference worksheets that accompany them.

Modules `01` through `08` cover the wet lab, from study design through library preparation, sequencing and run QC. `DL01` through `DL10` cover the dry lab, working through analysis in CZ ID. `-I` is Illumina, `-O` is Nanopore, and no marker means the file applies to both.

Decks are published as PDFs on the [resources site](https://cmtato.github.io/Rapid-Response-Resources/) and worksheets as web pages, with a button on each page to download the original. One exception is the ONT concat fastq worksheet, which only works in Excel, so it is download-only and linked from the DL03 deck.
