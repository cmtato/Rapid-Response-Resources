# Protocols

The bench worksheets that calculate reagent volumes, and reagent reference lists. The protocols themselves are published on protocols.io, as the [Rapid Response Metagenomics Protocols](https://doi.org/10.17504/protocols.io.8nlk5b4nwl5r/v1) collection.

Numbers follow the matching entry on protocols.io, so they are not consecutive. `AppendixA` marks reference material rather than a step. `-I` is Illumina, `-O` is Nanopore, and no marker means the file applies to both.

Every file here also has a page on the [resources site](https://cmtato.github.io/Rapid-Response-Resources/), and five of the worksheets have a live calculator that works out volumes from the number of reactions you enter. Download the original from a worksheet's page if you want to fill it in offline.
