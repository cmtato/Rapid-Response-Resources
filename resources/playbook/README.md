# Playbook

Templates, trackers and guidance for planning and running an mNGS training workshop.

`PB00` is the playbook itself, published as a page on the [resources site](https://cmtato.github.io/Rapid-Response-Resources/playbook/training-playbook/index.html). Its resource table links to each of the other files, `PB01` through `PB16`, which are kept here as editable originals rather than being converted, since they are meant to be filled in.
